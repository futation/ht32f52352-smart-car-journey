# 06 · 串口数据包协议

本项目与外界通信的唯一方式：**中断里做状态机拼包，主循环里只看标志位**。协议在两路串口（蓝牙 UART0、扫码枪 USART1）上复用，实现见 `drivers/UART0/` 与 `drivers/Scaner/`。

## 协议格式

```
@  payload  .
包头      包尾
```

- 包头 `@`、包尾 `.`，负载为可读文本；
- 命令语义由命令层解释：

| 指令 | 含义 |
| --- | --- |
| `@Forward.` / `@Backward.` / `@Left.` / `@Right.` / `@Stop.` | 动作 |
| `@CWRotate.` / `@CCWRotate.` | 原地旋转 |
| `@SetSpeed:50.` | 设速（命令层限幅 20~100） |
| `@F3_1_M2.` | 路径：前进 3 格 → 转向（1 左 / 2 右）→ 再走 2 格 |
| `@Return.` | 按记录路径原路返回 |
| 扫码枪回传的格子编号 | 与蓝牙路径比对，一致触发 EMG STOP |

## 接收侧：中断状态机拼包

```c
switch (RxState) {
case 0:                                   // 等包头
    if (RxData == '@' && Serial_RxFlag == 0) {
        RxState = 1;
        pRxPacket = 0;
        Serial_RxPacket[pRxPacket++] = RxData;
    }
    break;
case 1:                                   // 收负载
    if (RxData == '.') {                  // 包尾
        Serial_RxPacket[pRxPacket++] = RxData;
        Serial_RxPacket[pRxPacket] = '\0';
        Serial_RxFlag = 1;                // 通知主循环
        RxState = 0;
    } else {
        if (pRxPacket < SERIAL_RX_PACKET_SIZE - 1)
            Serial_RxPacket[pRxPacket++] = RxData;
        else {                            // 超长防护：整包丢弃
            RxState = 0;
            pRxPacket = 0;
        }
    }
    break;
}
```

三个健壮性设计：

1. **`Serial_RxFlag == 0` 才开收**——上一包未被主循环处理完之前，新包直接丢弃，避免半包覆写（代价是突发包会丢，适合低频命令场景；高频场景应改双缓冲）；
2. **长度防护**——负载超长整包作废，绝不溢出；
3. **`'\0'` 显式收尾**——主循环可以安全地 `strcmp/sscanf`。

## 发送侧：环形缓冲 + TXC 中断

应用层只把字节写入 `txd_comm0` 环形缓冲（关中断保护 `cnt++`），使能 TXC 中断；ISR 一次填满硬件 FIFO，缓冲空则自动关 TXC 中断。效果：`UART0_SendString()` 对主循环零阻塞。

⚠️ 注意临界区粒度：对 `cnt`、写指针这类与 ISR 共享的变量，任何非原子的读改写都要 `NVIC_DisableIRQ / EnableIRQ` 包裹（`drivers/UART0/UART0.c` 中的写法可直接参考）。

## 命令层

```c
if (Serial_RxFlag) {
    char *rxData = (char *)Serial_RxPacket;

    if      (strcmp(rxData, "@Forward.") == 0) { Move_Forward(speed);  isMoving = 1; }
    else if (strcmp(rxData, "@Stop.")    == 0) { Car_Stop();           isMoving = 0; }
    else if (sscanf(rxData, "@SetSpeed:%d.", &speed) == 1) { /* 限幅 20~100 */ }
    else if (sscanf(rxData, "@F%d_%d_M%d.", &motion.savedForward,
                                           &motion.savedFace,
                                           &motion.savedMove) == 3) {
        motion.state = STATE_MOVING;      // 交给运动状态机（docs/05 §应用）
    }
    else UART0_SendString("Unknown Command!");

    Serial_RxFlag = 0;                    // 处理完才清标志
}
```

动作类命令用 `strcmp` 全匹配——隐性地完成了完整性校验，误码包到不了执行层。

## 双串口复用

UART0 与 USART1 的 ISR 结构完全同构，仅缓冲与标志不同（`Serial_RxFlag1`）。协议层不绑定具体串口外设，是新串口设备接入时可以直接复用的模板。

## 已知不足与改进方向

- **无校验和**：动作命令靠全匹配兜底，但 `@F...` 参数类命令没有防错——加一个 LRC/CRC8 字节更稳；
- **单缓冲**：解析期间不收新包，牺牲吞吐换安全；改为双缓冲（或环形包队列）可同时兼顾；
- **无转义**：负载中不能出现 `@` 和 `.`，二进制负载场景需要转义机制。
