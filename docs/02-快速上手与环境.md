# 02 · 快速上手与环境

## 硬件与软件

| 项 | 内容 |
| --- | --- |
| 主控 | Holtek **HT32F52352**（Cortex-M0+，48MHz，64KB Flash / 8KB RAM） |
| IDE | Keil MDK-ARM v5（工程：`project/HT32F52352_SmartCar_PID/Project/Templete.uvprojx`） |
| 固件库 | Holtek HT32F5xxxx 标准外设库 + CMSIS（已含在工程内） |
| 器件包 | Holtek 官网 HT32F5xxxx Device Family Pack |

## 编译

1. 打开 `Templete.uvprojx`；
2. 装好器件支持包；
3. Rebuild。仓库已清除 `Output/`、`Listing/` 等编译产物，首次编译自动重新生成。

只想在台架上验证电机/PID 而没有整车？把 `User/main.c` 的外设初始化裁剪到只剩 Motor 相关（`Motor_Init()` + `BFTM1_Configuration()`）即可。

## 工程目录约定

```
工程根/
├── Hardware/     ← 自写驱动（每个模块一对 .c/.h，自包含）
├── User/         ← main.c + ht32f5xxxx_01_it.c（中断服务）
├── Libraries/    ← 官方固件库（不手改）
├── Utilities/    ← 官方板级支持
├── Project/      ← Keil 工程文件
└── Doc/          ← 笔记
```

`Hardware/User` 分层的价值：模块之间只通过头文件函数交互，任何模块可以整体拷进新工程——本仓库 `drivers/` 就是按这个标准提炼的。

## 把 drivers/ 里的模块抄进你的工程

1. 拷贝对应目录的 `.c/.h` 到你的 `Hardware/`；
2. Keil 里添加源文件与头文件包含路径；
3. 外设时钟与 AFIO 时钟已在每个 `XXX_Init()` 内部使能，无需重复配置；
4. 引脚定义在各文件顶部宏，按自己的硬件修改；改引脚前先过一遍 [09 引脚分配](09-引脚分配与冲突检查.md) 的冲突检查思路。

## 从 STM32 例程迁移到 HT32：主要差异点

本项目的驱动大多从 STM32 教程例程移植而来，以下是反复遇到的 API 差异，供同样拿着 STM32 例程往 HT32 搬的人参考：

| 事项 | STM32 (HAL/寄存器例程) | HT32 标准库 |
| --- | --- | --- |
| 外设时钟 | `__HAL_RCC_GPIOx_CLK_ENABLE()` 一类宏 | `CKCU_PeripClockConfig_TypeDef` 结构体按位域填 `Bit.PC = 1` 后一次使能；**AFIO 时钟也要单独使能**，容易漏 |
| 引脚复用 | GPIO Init 时选 `MODE_AF` | 必须显式调 `AFIO_GPxConfig(GPIO_Px, AFIO_PIN_n, AFIO_FUN_xxx)`；同一引脚可在运行时反复切换复用功能（本项目舵机急停就是靠切回 `AFIO_FUN_GPIO` 实现的） |
| GPIO 输出 | `HAL_GPIO_WritePin()` | `GPIO_SetOutBits()/GPIO_ClearOutBits()/GPIO_WriteOutBits()`，且先 `GPIO_DirectionConfig(..., GPIO_DIR_OUT)` |
| GPIO 输入 | 直接读 IDR | `GPIO_ReadInBit()`，且引脚需配为输入方向并 `GPIO_InputConfig(..., ENABLE)`——**配成输出方向时读不到外部电平**，软件 I2C 读 ACK 时必须切方向 |
| 定时器 | TIM 家族，HAL_TIM | `TM_` 系列函数（`TM_TimeBaseInit/TM_OutputInit/TM_DecoderConfig`），定时器分 BFTM/GPTM/MCTM/SCTM 四类，能力差异大，选型见[下一篇](03-定时器家族与资源分配.md) |
| 正交解码 | TIM Encoder Mode | `TM_DecoderConfig(HT_GPTMx, TM_SMSEL_DECODER3, ...)`，计数器直读 `TM_GetCounter()` |
| 串口 | USART | API 近似（`USART_Init`），但中断标志清除用 `USART_ClearFlag`，发送完成用 TXC 标志 |
| 中断服务 | `stm32fxxx_it.c` | `ht32f5xxxx_01_it.c`，函数名同规则（`XXX_IRQHandler`） |

> 上表基于本项目实际用到的外设，未覆盖的部分以 Holtek 官方固件库用户手册为准。

## 固件库注意事项

- `Libraries/` 内容不要手改；芯片相关的宏在 `ht32f5xxxx_01.h`，工程配置在 `ht32f5xxxx_conf.h`；
- `SystemCoreClock` 默认 48MHz，所有分频计算（BFTM 比较值、PWM 周期、波特率）都基于它；
- 看门狗若被使能，主循环需周期性 `WDT_Restart()`（本工程 main.c 里有保留代码）。
