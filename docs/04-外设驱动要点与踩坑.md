# 04 · 外设驱动要点与踩坑

逐模块整理实现要点与踩过的坑。源码：`drivers/<模块>/`，引脚：[09 引脚分配](09-引脚分配与冲突检查.md)。

## LED（`drivers/LED/`）

PC14 推挽输出。最小工程骨架，用于打通"时钟使能 → GPIO 方向 → 输出"流程。

## 阻塞延时（`drivers/delay/`）与非阻塞定时器（`drivers/Noblo_Delay/`）

- `delay/` 基于 SysTick 的阻塞 `Delay_ms/Delay_us`，仅用于初始化序列；
- 主循环里的定时一律用 `Noblo_Delay` 的软定时器实例，设计与误用分析见 [05 非阻塞软定时器设计](05-非阻塞软定时器设计.md)；
- 时基来自 BFTM0 1ms 中断（`drivers/BFTM0/`），控制周期来自 BFTM1（`drivers/BFTM1/`）。

## OLED（`drivers/OLED/`）

SSD1306，**软件 I2C：PC12=SCL、PC11=SDA**。从 STM32 例程移植，只需替换 GPIO 读写宏。

- ⚠️ **坑**：软件 I2C 读从机 ACK 时必须把 SDA 临时切回输入方向（HT32 输出方向下读不到外部电平，与 STM32 寄存器直读 IDR 不同）；
- ⚠️ **坑**：PC11/PC12 这类"随手选"的引脚很容易和后续外设撞车（本项目编码器就撞在了 PC11 上，见 [03](03-定时器家族与资源分配.md)）。

## 蓝牙 UART0（`drivers/UART0/`）

HC-06，PC4=TX / PC5=RX @9600。

- 发送：环形缓冲 + TXC 中断，`UART0_SendString` 对主循环零阻塞；
- 接收：中断内状态机拼包（`@` 包头、`.` 包尾），协议详见 [06 串口数据包协议](06-串口数据包协议.md)；
- ⚠️ **坑**：对 `cnt` 等共享变量的读写要用关中断临界区保护（代码里 `NVIC_DisableIRQ` 的位置就是为此）。

## 扫码枪 USART1（`drivers/Scaner/`）

USB 扫码枪（串口输出），PB15=TX / PC0=RX @9600。与 UART0 完全同构的缓冲结构——**同一套协议范式在两路串口复用**，主循环处理逻辑一致。

## 电机（`drivers/MCTM0/` + `drivers/Motor/`）

一路电机 = 1 路 PWM + 2 个互斥方向脚：

| 资源 | 左电机 | 右电机 |
| --- | --- | --- |
| PWM（MCTM0） | PB8 = CH3 | PB6 = CH2 |
| 方向脚 | PC2 / PC9 | PA8 / PA9 |

要点：

- `LeftMotor_SetSpeed(-100~100)`：符号→方向脚电平，绝对值→占空比，上层永远不碰引脚；
- 积分限幅 + 输出限幅双保险（±1000 / ±100）；
- `MCTM0_CHx_DisablePWMOutput()` 把引脚切回 GPIO 拉低，急停比"占空比 0"更干净；
- MCTM0 多余通道（CH0/CH1）的配置一律删掉，避免无意义的初始化开销。

## 编码器（`drivers/GPTM0/` + `drivers/GPTM1/`）

GPTM 硬件正交解码（四倍频），配置三行搞定，详见 [07](07-编码器测速与双环PID.md)。

- ⚠️ **坑（实测）**：外部中断数脉冲的方案在高转速下中断过载、丢计数，测速完全失真——已废弃，勿走弯路；
- ⚠️ **坑**：硬件计数器位宽有限，里程用"增量 + 软件累加"获得；
- ⚠️ **坑**：GPTM1 原引脚 PC11 与 OLED 冲突，迁至 PA1/PA0——引脚分配要先画表。

## 舵机（`drivers/Servo/`）

SG90，SCTM1 单通道 50Hz，PB3，0.5~2.5ms ↔ 0~180° 线性映射。

- 经验：舵机这类"单通道低要求"负载，从 SCTM 开始分配，别占用带解码/互补输出的好定时器；
- `Servo_Disable()` 运行时把 PB3 切回 GPIO 拉低（AFIO 复用动态切换），舵机上电抖动可用此法消除。

## 超声波 HC-SR04（`drivers/HCSR04/`）

PB0=Trig / PB1=Echo，SCTM0 作 1MHz 计数器测回波脉宽。

两个健壮性设计（可复用到任何回波测距场景）：

- **超时保护**：`while(等待边沿 && timeout--)`，回波丢失不死等；
- **有效值过滤**：连测 5 次只统计 2~400cm 的样本再取均值。

⚠️ **坑**：测距是阻塞式（单轮约 60ms×5），在运动控制主循环里调用要评估实时性影响。

## 红外避障（`drivers/Infrared_Sensor/`）

PA15=左 / PA14=右，上拉输入，**0 = 有障碍**。数字量直读，注意与超声波的职责分层：红外是"最后保险丝"，超声波负责"提前量"。

## 小车运动学 + 双环 PID（`drivers/Smart_car/` + `drivers/Motor/`）

前进/后退/差速转向/原地旋转的接口层 + 位置环/速度环串级控制。结构、参数与调参过程见 [07 编码器测速与双环 PID](07-编码器测速与双环PID.md)。

## MPU-6050（`drivers/MPU6050_failed/`）

两次未调通的移植存档（软件 I2C / 硬件 I2C1），根因为 I2C 地址约定混乱。作为案例完整分析见 [08](08-I2C地址约定与MPU6050移植案例.md)。
